# Perspective launch tower backup

Saved before the flat front-view revision on September 22, 2026.

`launch-tower.svg` preserves the original red tower, with visible side faces and a raised launcher deck.
`icon-composition.svg` is the complete, self-contained icon with that tower.
The PNG files show the tower, the composed icon, and the size comparison grid.
`compose.py` and `SOURCES.md` preserve the composition settings and source notes.
`SHA256.json` records the file checksums.

To restore the tower, copy `launch-tower.svg` into `docs/artwork/app-icon/`.
Then run the composition script in that directory.
